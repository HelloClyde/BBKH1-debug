# H1Debug v1.0.0

首次独立发布H1 / Y100 V1.41后台USB调试器及配套Codex skill。

- PC按键、单点触摸、480×272无损截图、RAM读写和原生测试模块。
- 不拔USB上传/覆盖完整BDA、刷新桌面并经原生载入器运行。
- 文件上传/下载/列表/状态、改名或同卷移动、删除、创建/删除空目录。
- 再次打开H1调试可关闭；后台调试不要求前台应用接入专用库。

发布BDA与2026-10-17真机验收文件逐字节一致。已通过V1→V2部署、文件管理、
后台内存/代码执行、触摸/按键、截图、10次串口重开、关闭及普通U盘恢复。
公开CI从源码构建，执行139项离线测试和2个独立GNU链接比较；私有完整固件与
真机验证是已有记录，通过精确SHA256绑定，不能把CI说成实时硬件测试。

下载 `H1Debug-install.zip` 后，将 `应用/程序/H1Debug.bda` 复制到内置存储。
安全弹出、拔线启动调试器，再连接USB。换过已运行的旧调试器时先重启设备。
普通目标BDA以后可保持USB连接更新。

`h1-debug-skill.zip`包含可安装的skill；`H1Debug-v1.0.0-source.zip`包含PC工具、
全部项目源码、skill及固定SDK快照/bundle。skill单独使用仍需要项目工具目录。
资产完整性见`SHA256SUMS.txt`和`release-manifest.json`。

只支持已验证固件；EXEC没有强制抢占/隔离，文件替换不承诺断电原子性。
