# H1Debug v1.0.3 预览版

补齐独立仓库此前未同步的带线启动和ESP调试桥支持，以及此次文件桥接提速的电脑工具。
- H1端通过短暂软件断开/重新枚举接管已插线的USB；等待期间保持调度，检测到原生服务竞争则放弃并恢复所有权。
- `--port esp://COM6`连接ESP USB2，H1继续接ESP USB1；实际端口需重新识别。
- ESP0.4.5使用921600 UART及事件唤醒；新电脑工具以只读INFO自动兼容旧115200固件，批量读取串口。
- 新增临时文件测速工具；仍使用原来的序号/CRC/文件事务/回滚与SHA256读回，不启用未经验证的RPC并发。
- 电脑工具和skill随源码及独立skill包发布。ESP固件由固定提交的H1 SDK提供，不重复打包另一份固件源码。

另测256KiB上传含提交校验21.953秒、下载13秒，无同大小旧版基线，不计算大文件提速比。
全部CRC/SHA256核对成功，临时文件清理，H1驻留image_id e14aaef1保持不变。
